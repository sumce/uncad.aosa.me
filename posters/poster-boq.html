清单工作流
U1F

清单生成

框选空图框执行 U1F：字段、容量与固定清单预检 →「填充确认」窗口逐行核对 → 单一 CAD 事务写入 → 自动输出 [BOQ]机台ID.xlsx。

U1U

清单更新

多图框批量更新：自动读取机台 ID 与设备名、统一预检、一个事务写入，任一失败整批回滚；重复更新按「机台 ID + 设备」覆盖。

U1S

当前图框提交

只读命令：不修改 CAD、不读机台 Excel，直接把现有图框的清单项、数量与米数独立重复提交到 BOQ，适合单独补交。

U1SET

配置中心

机台工作簿由用户选择、点击「刷新」才解析进本地 SQLite 快照 —— 源文件改动不会偷偷影响图纸，所见即所得、结果可复现。
